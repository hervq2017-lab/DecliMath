# Erreurs classiques à traquer (dans le cours ET dans la section « piège »)

| Domaine | Erreur fausse | Correct |
|---|---|---|
| Priorités | 8 + 6 × 4 = 56 | 8 + 24 = 32 |
| Identités | (a+b)² = a²+b² | a²+2ab+b² |
| Racines | √(a+b) = √a+√b ; √(x²) = x | √25 ≠ 3+4 ; √(x²) = \|x\| |
| Fractions | 1/2+1/3 = 2/5 | 5/6 (dénominateur commun) |
| Pourcentages | +20 % puis −20 % = retour | 100 → 120 → 96 |
| Équations | x² = 9 ⇒ x = 3 seul | x = 3 ou x = −3 |
| Produit nul | ab = 0 ⇒ a = 0 et b = 0 | a = 0 ou b = 0 |
| Inéquations | multiplier par un négatif sans changer le sens | on inverse le sens |
| Angles | triangle = 360° ; quadrilatère = 180° | 180° ; 360° |
| Aire/périmètre cercle | confondre πr² et 2πr | aire πr² ; périmètre 2πr |
| Pythagore | c = a+b ; appliquer sans angle droit | c² = a²+b² ; triangle rectangle |
| Unités | 1 m² = 100 cm² ; 1 h = 100 min ; 1 ha = 100 m² | 10 000 cm² ; 60 min ; 10 000 m² |
| Vitesse | v = t/d | v = d/t |
| Nombres premiers | 1 est premier ; 2 n'est pas premier | 1 non ; 2 oui |
| Dérivées | (uv)′ = u′v′ ; (u/v)′ = u′/v′ | u′v+uv′ ; (u′v−uv′)/v² |
| Logarithme | ln(a+b)=ln a+ln b | ln(ab)=ln a+ln b |
| Second degré | Δ = b²+4ac ; x = (b ± √Δ)/2a | b²−4ac ; (−b ± √Δ)/2a |
| Proba | P(A∪B)=P(A)+P(B) toujours | − P(A∩B) si non incompatibles |
| Division | 5 ÷ 0 = 0 | non définie |

Règle : une phrase qui **énonce** l'erreur pour la dénoncer (section piège) est légitime ; la même phrase présentée comme vraie est un bloquant.
